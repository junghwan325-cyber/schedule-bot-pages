누가 쓰나요

이 앱은 앱 소유자 한 사람만 사용합니다. 소유자 외의 사용자 데이터는 수집하지 않습니다.

어떤 Google 데이터에 접근하나요

  • Google 캘린더 일정: 소유자의 일정을 보여 주고, 만들고, 바꾸고, 지우고, 알림 시각을 계산하기 위해 읽고 씁니다.
  • 캘린더 목록(읽기 전용): 보기에 포함할 캘린더를 고르기 위해서만 사용합니다.
  • Google Tasks 할 일: 소유자의 할 일을 보여 주고, 만들고, 완료·미루기·삭제하기 위해 읽고 씁니다.

어디에 저장하나요

일정과 할 일의 원본은 Google에 그대로 있습니다. 되돌리기, 알림 발송 기록, 미룬 횟수처럼 Google에 없는 정보만 소유자의 개인 서버에 있는 파일(SQLite)에 저장하며, 이 파일은 소유자만 읽을 수 있습니다.

누구에게 전달되나요

  • 소유자가 텔레그램으로 보낸 문장과, 수정할 때 대상이 되는 일정의 제목·시각은 날짜와 시간을 해석하기 위해 AI 언어 모델 서비스로 전달됩니다. 그 외의 목적으로는 전달하지 않습니다.
  • 화면과 알림은 텔레그램을 통해 소유자에게만 보냅니다.
  • 데이터를 판매하거나 광고에 사용하거나 다른 사람과 공유하지 않습니다.

Google API 데이터 사용 제한

이 앱이 Google API로 받은 정보의 사용과 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

삭제와 권한 철회

소유자는 Google 계정 권한 페이지에서 언제든 이 앱의 접근 권한을 철회할 수 있고, 서버의 저장 파일은 소유자가 직접 삭제할 수 있습니다.

English summary

This app is used only by its owner. It accesses the owner's Google Calendar events, calendar list (read-only) and Google Tasks solely to show, create, change and remind about the owner's own schedule. Google remains the source of truth; only undo records and reminder bookkeeping are kept in a private file on the owner's server. The owner's messages, and the title and time of an item being edited, are sent to an AI language model service only to interpret dates and times. Data is never sold, used for ads or shared with others. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account permissions page.
